Default Dashboard gives new Craft users a useful dashboard from their first sign-in. Define the widgets once and let the plugin populate them instead of configuring every account by hand.

An empty dashboard is not much of a welcome. Build a shared set of widgets around the way the project actually works, and new users arrive to useful shortcuts, guidance and information from their first login.

## Features

- **Shared starting layout:** Define the dashboard widgets new users should receive.
- **Group dashboards:** Choose different source dashboards for individual user groups.
- **Automatic onboarding:** Populate an empty dashboard when a user first needs it.
- **Configure once:** Avoid recreating the same widget collection for every account.
- **Native widgets:** Use the dashboard widgets already available to the Craft project.
- **Consistent experience:** Give editors a predictable starting point across the team.
- **Project-owned setup:** Keep the default widget configuration with the site.
- **Override controls:** Decide whether existing widgets should be replaced and whether administrators should be excluded.
- **Configure it once:** Apply the starting layout when a user has no widgets of their own, without repeating the same setup account by account.
